# Amazon Prime Movies & TV Shows Dashboard

## Project Overview

This project is an interactive Power BI dashboard created to analyze Amazon Prime Movies and TV Shows data.

The dashboard provides insights into titles, ratings, genres, directors, countries, and release-year trends.

## Dashboard Features

- Total number of titles
- Ratings analysis
- Genre analysis
- Director analysis
- Country-wise distribution
- Movies vs TV Shows
- Release year trends
- Start and end year analysis

## Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## Project Domain

Data Analytics / Business Intelligence
